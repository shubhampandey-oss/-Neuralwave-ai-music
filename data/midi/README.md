# Raw MIDI Data

Place your training `.mid` or `.midi` files here.

### Example Sources
- **Lakh MIDI Dataset (LMD)**: https://colinraffel.com/projects/lmd/
- **Classical Piano MIDI (e.g. MAESTRO)**: https://magenta.tensorflow.org/datasets/maestro
- **Synthetic Test Data**: Generated automatically by the test suite and validation scripts.

Note: Raw copyrighted MIDI files should not be committed to source control.
