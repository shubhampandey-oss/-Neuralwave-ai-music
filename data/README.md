# Data Directory

This directory stores datasets for NeuralWave AI:
- `midi/`: Raw `.mid` and `.midi` files collected or uploaded for model training.
- `preprocessed/`: Tokenized sequence tensors and vocabulary mappings generated by the preprocessing pipeline.

## Guidelines
- Do not commit large external MIDI collections to git.
- For testing, a synthetic sample MIDI can be generated using `scripts/validate_pipeline.py`.
